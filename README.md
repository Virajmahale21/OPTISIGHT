# OPTISIGHT
OptiSight is an explainable hybrid deep-learning framework for five-level diabetic retinopathy screening. It fuses MaxViT-Tiny and DenseNet-121 features, reaching 85.45% accuracy and 0.933 QWK on APTOS 2019, and is validated on 103 IDRiD images. Grad-CAM++ heatmaps and a Flask interface support clinician review. Shift-related limits are reported.
